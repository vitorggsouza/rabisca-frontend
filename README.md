# 🖊️ Rabisca

## ℹ️ About the project

Rabisca is a simple and intuitive note-taking application designed to help you in your daily life.

---

## 🖥️ Technologies

### 🎨 Front-end

- **HTML and CSS**: structure the content and define the visual appearance of each page.
- **JavaScript**: adds interactivity, dynamism, and functionality to the pages.
- **Bootstrap**: speeds up development and makes it easier to create responsive pages.
- **Bootstrap Icons**: provides icons that enhance the website's visual identity.

### 🛠️ Development tools

- **npm**: manages JavaScript packages and dependencies.
- **esbuild**: minifies and bundles CSS and JavaScript files.

---

## 🚀 How to run

1. Clone this repository:

```bash
git clone https://github.com/vitorggsouza/rabisca-frontend.git
```

2. Access the project directory:

```bash
cd rabisca-frontend/
```

3. Install the dependencies:

```bash
npm install
```

4. Run the development script:

```bash
npm run development
```

5. Or run the production script:

```bash
npm run build
```
